# ҚАЗАҚ ТІЛІ PRO

**Абылай хан атындағы №140 қазақ орта мектебі**

5–9 сыныпқа арналған интерактивті қазақ тілі оқу платформасы.  
Технология: HTML + CSS + JavaScript (статикалық сайт, `localStorage`).

## Онлайн (телефон + компьютер)

GitHub Pages: https://mika-bio.github.io/qazaq-tili-pro/

## Қалай ашу

### Chrome-да бір файл (file://)

`qazaq-tili-pro-chrome.html` файлын Chrome-да ашыңыз  
(немесе zip ішіндегі `qazaq-tili-pro-chrome.html`).

### Модульдік нұсқа (жергілікті сервер)

```bash
cd qazaq-tili-pro
python3 -m http.server 8080
```

Браузер: http://localhost:8080

## Мүмкіндіктер

- Тіркелу / кіру, деректер `localStorage`-та
- Оқушы кабинеті: сабақтар, тапсырмалар, тесттер, оқу сауаттылығы, PISA, олимпиада, қателермен жұмыс, нәтижелер, жетістіктер
- Мұғалім панелі: оқушылар, нәтижелер, әлсіз тақырыптар, тапсырма беру
- XP, жетістіктер, диагностика, адаптивті қиындық
- Толық қазақ тіліндегі интерфейс (turquoise / cream / gold)
