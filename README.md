# ҚАЗАҚ ТІЛІ PRO

**Абылай хан атындағы №140 қазақ орта мектебі**

5–9 сыныпқа арналған интерактивті қазақ тілі оқу платформасы.  
Технология: HTML + CSS + JavaScript (статикалық сайт, `localStorage`).

## Онлайн (телефон + компьютер)

GitHub Pages: https://mika-bio.github.io/qazaq-tili-pro/

## Қалай ашу

### 1) GitHub Pages (ұсынылады)

Браузерде ашыңыз: https://mika-bio.github.io/qazaq-tili-pro/

### 2) Chrome-да бір файл (file://)

`qazaq-tili-pro-chrome.html` файлын Chrome-да ашыңыз  
(немесе zip ішіндегі `qazaq-tili-pro-chrome.html`).

### 3) Модульдік нұсқа (жергілікті сервер)

```bash
cd qazaq-tili-pro
python3 -m http.server 8080
```

Браузер: http://localhost:8080

## Жеке аккаунт (оқушы)

1. **Тіркелу** батырмасын басыңыз.
2. Аты-жөні, сыныбы (5-А … 9-Г), **өзіңіз ойлаған** логин және құпия сөзді жазыңыз.
3. Құпия сөзді қайталаңыз (кемінде 6 таңба).
4. Тіркелгеннен кейін сіздің сессияңызға ғана кіресіз — кабинетке өтесіз.

**Маңызды:** логин мен құпия сөзді ұмытпаңыз. Басқа адам сіздің пароліңізсіз аккаунтыңызға кіре алмайды. Сайтта ортақ/жария оқушы парольдері көрсетілмейді.

Құпия сөздер **SHA-256** хеш түрінде сақталады (ашық мәтін емес).

## Мұғалім аккаунты

Мұғалім аккаунтын **мектеп әкімшісі** береді.  
Басты бетте мұғалім/оқушы парольдері жарияланбайды.
