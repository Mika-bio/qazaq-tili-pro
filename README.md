# ҚАЗАҚ ТІЛІ PRO

**Абылай хан атындағы №140 қазақ орта мектебі**

5–9 сыныпқа арналған интерактивті қазақ тілі оқу платформасы.  
Технология: HTML + CSS + JavaScript (статикалық сайт, `localStorage`).

## Қалай ашу

### 1-тәсіл: жергілікті сервер (ұсынылады)

```bash
cd qazaq-tili-pro
python3 -m http.server 8080
```

Браузерде ашыңыз: [http://localhost:8080](http://localhost:8080)

> ES-модульдер үшін сервер қажет (файлды тікелей `file://` арқылы ашу кей браузерде жұмыс істемеуі мүмкін).

### 2-тәсіл: кез келген статикалық хостинг

Репозиторийді GitHub Pages немесе Netlify-ге орналастырыңыз — түбірдегі `index.html` бастапқы бет.

## Мүмкіндіктер

- Тіркелу / кіру, деректер `localStorage`-та
- Оқушы кабинеті: сабақтар, тапсырмалар, тесттер, оқу сауаттылығы, PISA, олимпиада, қателермен жұмыс, нәтижелер, жетістіктер
- 5–9 сыныптың барлық тақырыптары: теория + практика + тест
- Қателер журналы, XP және жетістіктер, бастапқы диагностика, адаптивті қиындық
- Мұғалім панелі: оқушылар, нәтижелер, әлсіз тақырыптар, тапсырма беру
- Толық қазақ тіліндегі интерфейс
