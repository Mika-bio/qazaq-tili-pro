# ҚАЗАҚ ТІЛІ PRO

**Абылай хан атындағы №140 қазақ орта мектебі** · 5–9 сынып · толық стек платформа

Заманауи дизайн (ақ / аспан көк / янтарь). Ескі turquoise SPA толық алмастырылған.

## Іске қосу (нақты платформа)

```bash
npm install
npm start
```

Браузерде ашыңыз: `http://localhost:3000`  
Телефоннан: компьютермен **бір Wi‑Fi**-да болып, `http://КОМПЬЮТЕР_IP:3000` ашыңыз.

> **GitHub Pages Express-ті іске қоса алмайды.** Pages тек статикалық файлдарды көрсетеді. Толық платформаны (`API + SQLite + кабинеттер`) тек `npm start` арқылы мектеп/үй серверінде іске қосыңыз. Репозиторий түбіндегі `docs/pages-landing.html` — Pages үшін қарапайым ескерту беті (міндетті емес).

## Мұғалім (тек README / админ)

| Логин | Құпиясөз |
|-------|----------|
| `teacher140` | `Teacher140!` |

Басты бетте мұғалім логині **көрсетілмейді**. Мектеп кодымен жаңа мұғалім тіркеу: `140MEKTEP`.

## Оқушы

1. «ОҚУШЫ РЕТІНДЕ КІРУ» → **Тіркелу**
2. Аты-жөні, сынып (5-А … 9-Г), логин, құпиясөз
3. Кабинет: сабақтар, тапсырмалар, тест, олимпиада, сауаттылық, PISA, қатемен жұмыс, нәтиже, прогресс, мұғалім пікірі

## Сындарлы ағын

Мұғалім кіреді → сынып → тапсырма береді → оқушы орындайды → авто-тексеру → қате сақталады → мұғалім көреді / пікір жазады → оқушы «Мұғалімнің кері байланысы» бөлімінде көреді → прогресс жаңарады.

## Құрылым

```
server/          Express API, SQLite, JWT, seed
public/          Жаңа frontend (mobile-first)
data/            qazaq.db (автоматты)
```

Құпиясөздер: SHA-256 хэш. Ашық мәтін сақталмайды.

## Қайта seed

```bash
node server/seed.js --force
```

## Техника

- Node.js 18+
- Express + better-sqlite3 (немесе sql.js fallback)
- JWT сессия
- Бір портта API + static (`npm start`)
